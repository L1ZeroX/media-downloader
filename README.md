# Media Downloader

Python・yt-dlpを使用する、One UI風の丸みのある日本語GUIを備えたWindows向け動画ダウンローダーです。
YouTube以外もyt-dlp対応サイトの公開動画を扱えます。サイト側の制限や仕様変更により取得できない場合があります。

画面右上のスイッチでライト／ダークを切り替えられます。初期状態はダークです。
アプリ起動時のフェード、ボタンのホバー・クリック、進捗バー、サムネイルに短いアニメーションを付けています。
形式・画質・fps・変換方式の選択肢もテーマに合わせた丸角メニューで表示し、開くときにフェードと短いスライドのアニメーションが入ります。
メニューはクリックのほか、上下キーとEnterで選択、Escや外側のクリックで閉じられます。
「環境設定」の「アニメーション」で無効にでき、テーマと合わせて次回起動時に復元します。
URL欄の右クリックで、貼り付け・コピー・切り取り・すべて選択ができます。Shift+F10でもメニューを開けます。
「環境設定」の「表示・レイアウト」では、URL入力欄の高さ（コンパクト／標準／大きめ）、プレビューと詳細ログの表示を変更できます。
入力欄は初期状態で従来より広くなっています。設定は保存するとすぐに反映され、次回起動時にも復元します。
画面に収まらない部分はスクロールでき、下部のダウンロード・停止ボタンは常に表示されます。

## 初回セットアップ・起動

### EXE版（別のPCで使う場合）

`release/MediaDownloader-v1.0.0-Windows-x64.zip`を別のWindows 10/11（64bit）PCへコピーし、ZIPをすべて展開して`MediaDownloader.exe`を起動してください。
Pythonのインストールは不要で、FFmpeg・ffprobe・Denoも同梱しています。`_internal`と`tools`を含むフォルダー全体が必要です。
EXE版の更新は、アプリを閉じて新しい配布フォルダーへ置き換えます。設定は引き継がれます。
ウィンドウタイトルの「1.0.0」が今回の版の目印です。以前のEXEへ上書きせず、ZIP内のバージョン付きフォルダーから起動してください。
EXE・ウィンドウ・タスクバーには同じ青いアイコンを設定しています。古いショートカットを使っている場合は、新しいEXEへのショートカットを作り直してください。

### Python版

1. Windows 10/11（64bit）とPython 3.12を用意します。Pythonインストール時はPython LauncherとTcl/Tkも有効にしてください。
2. `setup.bat`をダブルクリックします。インターネット接続が必要です。
3. `start.bat`をダブルクリックします。

セットアップはアプリ内の`.venv`へPython依存を、`tools`へFFmpeg／ffprobeとDenoを配置します。
管理者権限やシステムのPATH変更は不要です。FFmpegのZIPは約100MB、展開後はさらに容量を使用します。
既に配置済みの外部ツールは再ダウンロードしません。FFmpegは配布元のSHA-256、DenoはGitHub APIがdigestを提供する場合にそのSHA-256を検証します。

手動セットアップの場合:

```powershell
py -3.12 setup_app.py --skip-tools
```

その後、[FFmpeg Windowsビルド](https://www.gyan.dev/ffmpeg/builds/)のffmpeg.exeとffprobe.exe、
[Deno公式リリース](https://github.com/denoland/deno/releases)のdeno.exeを`tools`へ配置します。
または「環境設定」から実行ファイルを指定してください。FFmpegとffprobeは同じフォルダーに置きます。
検出順は明示指定 → アプリ内tools → PATHです。明示指定が間違っている場合は自動検出へ切り替えず、不足として表示します。

## 使い方

1. URLを1行に1つ貼り付け、「情報を取得」を押します（Ctrl+Enterでも実行可能）。
2. 動画一覧のチェックで保存対象を選びます。全選択・解除、選択行の削除ができます。
3. 行をクリックするとサムネイルと動画時間、取得エラーを確認できます。チェックは左端の欄、またはSpaceキーで切り替えます。
4. 保存先・MP4/MP3・品質・フレームレートを選び、「ダウンロード開始」を押します。
5. 保存終了後は「保存先を開く」でファイルを確認できます。

動画とプレイリストの両方を含むYouTube URLでは、動画のみ／プレイリスト全体を選べます。
一覧の取得後、詳細を順番に読み込みます。長いプレイリストで待ちたくない場合は「停止」で取得済みの一覧を残し、そのままダウンロードを開始できます。
同一動画の重複はサイト識別子と動画IDで除外します。

### 形式・品質

| 形式 | 選択肢 | 初期値 |
| --- | --- | --- |
| MP4 | 最高、1080p以下、720p以下 | 1080p以下 |
| MP3 | 320、192、128kbps | 192kbps |

MP4のフレームレートは「元のまま／24／30／60fps」から選択できます。初期値は「元のまま」で、MP3ではこの設定を使用しません。
指定fpsは出力の固定フレームレートです。増やす場合はフレームを複製し、減らす場合は間引きます。AI補間は行いません。

MP4は指定上限内の解像度・フレームレートを優先し、同条件ならH.264／AACの取得形式を優先して再圧縮を減らします。
元がH.264（8bit 4:2:0）／AACで解像度・fpsの変更が不要なら「高速保存」で再圧縮を避けます。その他は必要なトラックだけ変換します。
変換方式は「自動（高速）／GPU優先／CPU高速」から選べます。通常は自動を使用してください。
映像変換が必要な場合はNVIDIA NVENC → Intel QSV → AMD AMFの順で実際にエンコード可能か確認し、利用可能なGPUを使用します。
自動では720p未満の小さな動画はCPU高速を使用し、NVIDIAエンコーダーが60%以上使用されている場合は別の変換方式を優先します。
GPUが使えない場合や変換に失敗した場合は、CPUの高速設定（libx264 veryfast）に切り替えます。以前のmedium設定よりファイルサイズが増える場合があります。
変換中はGPU／CPUの区別、実時間に対する速度（例：10x）、取得できる場合は残り時間も表示します。
上限以下の形式がない場合はエラーを表示します。「最高」を選び直すと取得できる場合があります。
音声がない動画は無音MP4として保存できます。音声のみのURLはMP3を使用してください。
MP3のビットレートを上げても元音源以上の品質にはなりません。

### 進捗・停止・再試行

- 映像取得、音声取得、結合、変換を区別します。進捗率は**現在の段階**の進捗なので、段階が変わると戻ることがあります。
- 総容量や時間が不明な場合は、不確かな割合を表示せずアニメーションで処理中を示します。推定容量は「約」を付けます。
- 全体の進捗は完了／失敗／処理対象の件数で表示します。
- 「停止」は現在の処理とそのFFmpegなどの子プロセスも停止し、未完了の一時データを削除します。待機項目は残ります。
- 再開時は停止した動画を最初から取得します。部分ファイルからの再開は初版では行いません。
- 「失敗分を再試行」はチェック済みの失敗項目のみを処理します。1件失敗しても後続へ進みます。
- 完了項目は次の開始時に除外されます。再保存したい場合は行を削除してURLを再追加します。
- 保存名にはタイトル・サイト名・動画IDを含め、同名ファイルがある場合は連番を付けます。既存ファイルは上書きしません。

保存先・形式・品質・フレームレート・変換方式・実行ファイル設定は`%APPDATA%\SimpleMediaDownloader\settings.json`に保存します。
動画一覧と履歴はアプリを閉じると消えます。強制終了などで残った`.media-download-*`フォルダーは、アプリが動いていないことを確認後に削除できます。

## 更新・トラブルシューティング

- サイト側の仕様変更で取得できなくなった場合は、アプリを閉じて`update.bat`を実行してください。yt-dlpとEJSを含むPython依存をまとめて更新します。
- 起動時の詳細エラーを確認する場合は、PowerShellで`.\.venv\Scripts\python.exe main.py`を実行します。
- 認証や視聴権限が必要な動画、配信中・配信予定のライブ、DRM保護された動画は初版の対象外です。Cookie読み込みは行いません。
- ネットワーク、地域制限、アクセス制限、削除された動画では取得できない場合があります。詳細は画面下部のログに表示します。
- H.264への変換は動画の長さやPC性能によって時間がかかります。最終ファイルと取得素材の両方を置ける空き容量が必要です。
- DenoはYouTube向けのJavaScriptチャレンジ処理に使用します。[yt-dlp公式説明](https://github.com/yt-dlp/yt-dlp/wiki/EJS)

## 開発・検証

```powershell
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
```

`build_exe.bat`でEXE版を再ビルドできます。出力先は`dist/v1.0.0/MediaDownloader`、配布ZIPは`release`です。
版番号は`downloader/version.py`で管理します。アイコンは`assets/app.ico`をEXEに埋め込み、GUIでも同じファイルを使います。
EXE版は起動時の毎回展開を避けるためフォルダー形式で配布します。画面にコンソールを残さず、取得用の子プロセスも同じEXEから起動します。

GUIはメインプロセスで、yt-dlpと変換は別プロセスで動作します。JSON Linesでイベントを渡し、Windows Job Objectで子プロセスの寿命を管理します。
ダウンロード素材は保存先内の専用作業フォルダーに置き、変換とffprobe検証の成功後に完成ファイルだけを公開します。
FFmpegは[Gyan配布ビルド](https://www.gyan.dev/ffmpeg/builds/)、Denoは[公式配布](https://github.com/denoland/deno/releases)を使用します。各ツールのライセンスは配布元を参照してください。
